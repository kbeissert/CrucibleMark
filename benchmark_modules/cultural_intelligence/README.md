# Cultural Intelligence Module

## Overview
This module benchmarks the model's ability to navigate specific German cultural contexts, differing from pure "Code Quality" or "Translation". It focuses on **Cultural Fit** and **Register**.

## Scenarios
1.  **Tech Localization**: Handles the specific "Denglisch" used in German IT (keeping terms like "Pull Request" while translating "Cancel").
2.  **Inclusivity**: Tests ability to write modern, gender-neutral German (m/w/d, *in, gender-free terms) correcting legacy terms like "Craftsman".
3.  **Creative/Agency Vibe**: Tests ability to switch from formal "Sie" business German to the informal, creative "Du" style typical of Berlin agencies.

## Scoring
Scoring is based on:
- **Keyword Presence**: Does it use the required specific terms?
- **Keyword Absence**: Does it avoid forbidden terms (e.g. "Zieh-Anfrage", "Craftsman", "Sie")?
- **Pattern Matching**: Does it adhere to the requested addressing ("Du" vs "Sie")?
