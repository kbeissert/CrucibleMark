fix: resolve routing, caching and parsing bugs in llm judge

- Fixed critical `sys.modules` collision bug in `module_loader.py` causing
  subsequent test modules to load the cache of the first module. Dynamic
  modules are now loaded with a strict unique naming scheme.
- Refactored `run_benchmark.py` to extract correct `test_class` dynamically
  from the overridden configs instead of a hardcoded fallback.
- Boosted tokenizer handling for local Ollama providers inside
  `judge_config.py` from 1024 to 4096 `max_tokens` to prevent CoT truncation.
- Enhanced robustness of parser Regex inside `judge_parser.py` to properly
  extract scores surrounded by deep Markdown heading chains or bolded keys.
- Augmented leaderboard metadata values for doc and ux writing modules.
- Updated technical memory and agent guidelines tracking namespace traps.
