# Golden Standards

This directory contains the reference outputs (Golden Standards) for the benchmark assets.
These are generated by high-quality commercial models (e.g., Claude 3.5 Sonnet, GPT-4o) and serve as a baseline for semantic similarity comparison.

## Structure

- `golden_standards_scores.csv`: Summary of scores achieved by the reference models.
- `<model_name>/`: Folder containing the full JSON responses for each asset.
